# Changelog - MERI-PARO

## Version History

### v1.0.0 - 2026-07-21
**Initial Release**

#### Features
- Resume file upload (PDF, DOCX, TXT)
- AI-powered resume analysis
- Skill extraction and classification
- Experience parsing and assessment
- Education information extraction
- Career recommendations
- Resume scoring (0-10)
- Analysis reporting
- Docker support

#### Backend
- Flask REST API
- PostgreSQL database
- Redis caching
- NLP processing
- Model inference

#### Frontend
- React-based UI
- File upload interface
- Analysis results display
- Report generation
- Responsive design
